Getting Started

Requirements

  • Windows 64-bit (primary supported platform)
  • Java 17+ runtime
  • Internet connection (for online show/episode lookups)

First Launch

  1. Download TVRenamer.exe or the JAR file
  2. Run the application
  3. On first run, you may want to open Preferences (Ctrl+P) to configure:
    • Destination directory (where renamed files go)
    • Rename format (how filenames are structured)
    • Episode ordering preference (Aired vs DVD)

Quick Start: Rename Your First File

Step 1: Add Files

Drag and drop video files onto the TVRenamer window.

Step 2: Wait for Lookup

TVRenamer will parse the filename, identify the show, and look up episode information from the selected data provider (TVMaze by default). You'll see:

  • Current Name - The original filename
  • Proposed Name - What it will be renamed to
  • Status - Whether the file is ready to rename

Step 3: Review and Fix Issues

If TVRenamer can't identify a show:

  • Check if the filename has recognizable show name and episode numbers
  • Use Show Overrides in Preferences to help matching
  • If multiple shows match, you'll be prompted to choose the correct one

Step 4: Rename

Make sure the checkbox is ticked on each row you want to process, then click the action button. Its label follows your Preferences: Rename Checked, Move Checked, or Rename & Move Checked.

Tip: The action button works on ticked rows, not on highlighted (selected) ones. Untick any row you want to leave alone for now.

Understanding the Interface

Main Table Columns

Column Description
✅ (checkbox) Whether the row is processed when you click the action button
Current File Original filename (before renaming)
Proposed File Name / Proposed File Path New name after renaming (the full destination path when moving is enabled). Shows the reason if parsing or lookup failed.
Status Icon showing ready (✓), error, or in-progress state

Keyboard Shortcuts

Shortcut Action
Ctrl+A Select all files
F1 Open Help
Ctrl+P Open Preferences
Ctrl+Q Quit application
Delete / Backspace Remove selected files from list
