Adding Files

TVRenamer provides several ways to add video files for renaming.

Drag and Drop

The easiest way: simply drag video files from Windows Explorer and drop them onto the TVRenamer window.

  • You can drag individual files or entire folders
  • Folders are scanned recursively, including subfolders
  • Hidden files are skipped, as are files matching an Ignore Keywords entry (see Preferences)

Add Files / Add Folder Buttons

The Add files and Add Folder buttons at the bottom of the window open a standard file or folder picker. They work the same way as drag and drop.

Note: Folders, whether dropped, picked with Add Folder or set as the preload folder, are only added while Recursively add shows in subdirectories is enabled in Preferences (it is on by default). With it off, only individual files can be added.

Preload Folder (Automatic)

Configure a folder in Preferences that TVRenamer will automatically scan on startup:

  1. Open Preferences (Ctrl+P)
  2. Find "Preload folder" and enable it
  3. Select or type the folder path
  4. Save preferences
Tip: Use the preload folder for your download directory. TVRenamer will automatically show new episodes when you launch it.

Supported File Types

TVRenamer does not filter by extension: any file whose name contains a show name and an episode number can be added and renamed. That is usually a video file (.mkv, .mp4, .avi and so on), but it also covers subtitle files.

Adding subtitle files (.srt, .ass, .ssa, .vtt) alongside their video is worthwhile: both are renamed to the episode's name, so they stay paired even if their original names differ, and they can then be merged into the video (see Subtitle Merging).

Filename Parsing

TVRenamer extracts show name and episode information from filenames. It recognizes patterns like:

Pattern Example
SxxExx Solar.Drift.S01E01.mkv
sXXeXX solar.drift.s01e01.mkv
XxXX Solar Drift 1x01.mkv
Multi-episode Show.S01E01-E02.mkv or Show.S01E01-02.mkv
Series_X_-_YY Show_Series_3_-_18.Title.mkv

When Parsing Fails

If TVRenamer can't parse a filename, the "Proposed Name" column will show a specific reason:

  • No show name found - Can't identify the show name portion
  • No season/episode pattern - Missing S01E01-style numbering
  • Filename too short - Not enough characters to parse
Note: After adding files, TVRenamer shows a summary dialog if any files couldn't be parsed, listing the count and reasons.

Removing Files from the List

  • Select files and press Delete (or Backspace)
  • Clear List removes every row; Clear Completed removes only rows already processed

This only removes them from TVRenamer's list, not from disk.
