TVRenamer Help

TVRenamer is a utility to rename TV episode files using information from an online TV database. It supports two providers — TVMaze (the default, no setup) and TheTVDB (v4) — selectable in Preferences.

Quick Overview

TVRenamer takes ugly filenames like:

Solar.Drift.[6x05].DD51.720p.WEB-DL.AVC.mkv

And renames them to:

Solar Drift S06E05 Aphelion.mkv

Basic Workflow

  1. Add files - Drag and drop or set a preload folder
  2. Review matches - TVRenamer looks up show/episode info from the selected data provider
  3. Resolve any issues - Fix unrecognized shows or disambiguation prompts
  4. Rename - Tick the rows you want and click "Rename Checked" (or "Rename & Move Checked")

Key Features

  • Batch renaming of multiple shows at once
  • Customizable filename format with tokens
  • DVD/BluRay ordering support, not just aired order (TheTVDB v4 provider)
  • Multi-episode file handling (S01E01-E02)
  • Optional metadata tagging for MP4 and MKV files
  • Optional merging of subtitle files into MP4 and MKV files
  • Theme support (Light, Dark, Auto)
  • SMB/network share support

Getting Help

  • Report issues on GitHub
  • Enable debug logging with -Dtvrenamer.debug=true for troubleshooting
