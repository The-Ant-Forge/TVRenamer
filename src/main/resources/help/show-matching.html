Show Matching

TVRenamer extracts show names from filenames and looks them up with the selected data provider (TVMaze by default, or TheTVDB v4). This page explains how to handle matching issues.

How Matching Works

  1. TVRenamer extracts the show name from the filename
  2. It normalizes the name (removes punctuation, converts to lowercase)
  3. It searches the selected data provider for matching shows
  4. Results are matched against your files

Show Overrides

Override the extracted show name before searching. This helps when:

  • Your filenames use abbreviations (e.g., "CoA" instead of "Crown of Ages")
  • The show name is misspelled in your files
  • You want to force a specific search term

Adding an Override

  1. Open Preferences → Matching tab
  2. In the Overrides section, enter the extracted name and the replacement
  3. Click Add / Update, then Save

The extracted name is matched loosely: case, dots, underscores and most punctuation are ignored, so Solar_Drift, solar.drift and solar drift all count as the same name. Right-clicking a row and choosing Edit Matching Rule... fills in the name exactly as the provider was searched with it (the text in No info for "..." on an unfound row).

A new entry appears at the top of the table, so you can see what you just added without scrolling a long list; it takes its alphabetical place the next time you open Preferences. If you enter a name that is already in the table, that existing entry is updated rather than a second copy being added. To edit an entry, click its row first: the row you have selected is always the one that gets updated.

Both the Overrides and Disambiguations tables open sorted alphabetically by their first column. Click either value column heading to sort by that column instead, and click again to reverse the order. While an entry is being checked against the data provider, the headings are greyed and sorting is unavailable until the check finishes.

Shortcut: Right-click any row and choose Edit Matching Rule.... Preferences opens on the Matching tab with the override's Extracted show and the disambiguation's Query string filled in from that row, so you can see what TVRenamer extracted and searched for. Replace with starts as the current name, selected: type over it or edit it, click Add / Update, then save. Rows whose result would change are retried automatically. Right-click the file name rather than the Proposed File Path cell: a drop-down or link in that cell has its own right-click.

Show Disambiguation

When the data provider returns multiple shows matching your search, TVRenamer prompts you to choose the correct one.

Disambiguation Dialog

The dialog shows candidate shows sorted by match confidence:

  • Show name - The official title. The best match is marked with ★ Recommended and a similarity percentage when confidence is high.
  • Year - First aired year (helps distinguish reboots)
  • Provider ID - Unique identifier from the data provider
  • Aliases - Alternative names

Choosing a Show Yourself

To pick the show for a file at any time, including one that matched the wrong show, right-click its row and choose Choose Show.... TVRenamer searches the data provider again and opens the same dialog with every result, best match first. Select several rows to choose for several shows at once; rows with the same show name appear once. If the search finds nothing, TVRenamer says so and offers to open the Matching tab, with the same fields filled in, so you can search under a different name.

Your choice applies to every file with that show name, not just the row you clicked, and those rows are re-matched straight away.

Remembered Selections

Your disambiguation choice is saved automatically. Future files with the same query will use your selection without prompting.

A remembered selection is looked up by its Provider ID, so it keeps working even if the provider's name search stops returning that show. This also means you can add a Disambiguation row by hand with a show's ID when searching for its name finds nothing.

Clearing a Remembered Selection

  1. Open Preferences
  2. Find "Remembered Disambiguations"
  3. Find and remove the entry you want to reset

Automatic Selection

TVRenamer automatically selects a show without prompting when:

  • Only one show matches the search
  • One show is an exact (case-insensitive) match for the query
  • You have a remembered disambiguation for that query
  • Fuzzy matching finds a strong candidate (≥80% similarity with a clear lead over other options)

Fuzzy matching uses edit-distance comparison, so minor typos or small naming variations (e.g., "Crwon of Ages" vs "Crown of Ages") are resolved automatically.

Troubleshooting Match Issues

Show Not Found

When a show can't be found, the Proposed File Path column displays an "add a rule in Preferences > Matching" link. Click it to jump straight to the Matching tab with the show name pre-filled, then type the name to search for instead and save.

A provider's search can be literal about spacing: a filename that splits a run-together title into two words (or joins two words into one) may find nothing, while the title spelled the provider's way is found straight away. An override with the provider's spelling fixes this.

Other things to try:

  • Check the spelling in your filename
  • Search your data provider directly to verify the show exists and find its exact name (TVMaze or TheTVDB)
  • If a show you know exists keeps coming back as not found, the active provider's search may be degraded — try switching providers in Preferences (see Troubleshooting)

Wrong Show Selected

  • Right-click the row and choose Choose Show..., then pick the correct show. Every file with that show name is re-matched.
  • Or clear the remembered disambiguation in Preferences and re-add the files

Wrong Episodes

  • Check your Episode Ordering preference (Aired vs DVD)
  • Some shows have different numbering between versions
  • Verify your files use the expected numbering scheme
Tip: If a show has both US and UK versions (like "The Bullpen"), use the year to distinguish them. Adding an override like "The Bullpen US" → "The Bullpen (US)" can help.
